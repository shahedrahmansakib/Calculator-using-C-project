# Simple C++ Modular Calculator

A lightweight, modular, command-line calculator written in modern C++. This project demonstrates basic functional decomposition, input handling, basic arithmetic operations, and safety checks for zero-division errors.

---

## ✨ Features
- **Modular Architecture:** Functional breakdown for user input, operation selection, computation, and result rendering.
- **Arithmetic Operations:** Addition, Subtraction, Multiplication, and Division.
- **Edge-Case Handling:** Built-in validation for zero-division (`n1 / 0`) and invalid operator selections.
